# Gongmiri v0.2.0

릴리스 날짜: 2026-09-02

Gongmiri v0.2.0은 Shapefile ZIP을 빠르게 확인하는 흐름을 Chrome 팝업에 맞게 다시 설계한 릴리스입니다. React 기반 UI, 안정적인 대용량 속성 테이블, 지도 시각화, 데이터 내보내기와 새 브랜드 아이콘을 포함합니다.

## 주요 변경 사항

### Chrome 팝업 중심 UI

- 확장 아이콘에서 800×600 팝업 뷰어를 바로 실행합니다.
- 업로드 이후 지도, 컬럼 품질, 속성 테이블을 한 화면 흐름으로 정리했습니다.
- 지도 위에서 보기 모드를 바로 전환할 수 있도록 시각화 옵션을 단순화했습니다.
- 한국어·영어 UI, 라이트·다크 테마와 Pretendard Variable 폰트를 지원합니다.

### 지도와 데이터 탐색

- MapLibre 기반 Point, LineString, Polygon, MultiPolygon 미리보기를 제공합니다.
- 범주형·연속형 색상, 포인트 크기와 클러스터 시각화를 지원합니다.
- 지도와 속성 테이블의 활성 피처 상태를 공유합니다.
- 컬럼 품질을 3×3 카드와 페이지 이동으로 간결하게 확인할 수 있습니다.

### 속성 테이블 안정화

- React Data Grid 기반 가상 스크롤 테이블로 전환했습니다.
- 정렬, 컬럼 표시·숨김, 왼쪽·오른쪽 고정과 순서 변경을 지원합니다.
- Chrome 액션 팝업에서 표 스크롤이나 컬럼 메뉴를 조작할 때 화면이 위로 이동하는 문제를 방지했습니다.
- 팝업과 충돌하던 수동 컬럼 너비 조절 및 불필요한 조회 필터를 제거했습니다.

### 내보내기와 대용량 처리

- 전체 결과를 GeoJSON 또는 UTF-8 BOM CSV로 저장할 수 있습니다.
- 내보낼 컬럼과 GeoJSON 좌표계를 선택할 수 있습니다.
- Worker에서 내보내기 파일을 생성해 UI 중단을 줄였습니다.
- Quick/Full 모드와 대용량 경고, 진행률 및 취소 흐름을 제공합니다.

### 확장 프로그램 완성도

- 새 컬러 Gongmiri 아이콘과 흰색 원형 배경을 적용했습니다.
- 다운로드 ZIP 감지는 `downloads` 선택 권한을 사용할 때만 활성화됩니다.
- 불필요한 `<all_urls>` 웹 접근 공개 설정을 제거했습니다.
- React 전환, 다국어 메타데이터, 빌드 산출물 검증과 CI 구성을 반영했습니다.

- Chrome MV3 산출물 smoke check 통과
- npm 프로덕션 의존성 감사 결과 알려진 취약점 0건

## 알려진 제한

- 팝업 변경 후에는 `chrome://extensions`에서 확장을 새로고침해야 합니다.
- Quick 모드도 원본 ZIP을 먼저 파싱한 뒤 화면용 피처를 샘플링합니다.
- 매우 큰 Full 결과 내보내기는 브라우저 메모리 한계의 영향을 받을 수 있습니다.
