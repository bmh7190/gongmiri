# Gongmiri v0.2.1

릴리스 날짜: 2026-09-08

Gongmiri v0.2.1은 다운로드 ZIP 감지 상태를 안정적으로 유지하고, Shapefile 필수 파일이 빠진 ZIP을 더 명확하게 안내하는 유지보수 릴리스입니다.

## 주요 변경 사항

### 다운로드 ZIP 감지 안정화

- Chrome의 실제 `downloads` 권한을 기준으로 감지 기능의 활성 상태를 복원합니다.
- 팝업을 다시 열거나 확장 프로그램의 백그라운드 서비스 워커가 재시작돼도 감지 리스너를 동기화합니다.
- 확장 아이콘을 열면 ZIP 알림 배지를 확인 처리합니다.
- 기능을 끄거나 권한을 철회하면 최근 ZIP 메타데이터와 배지를 정리합니다.

### 잘못된 ZIP 안내 개선

- `.shp`, `.dbf`, `.shx` 필수 파일이 빠진 ZIP을 전용 모달로 안내합니다.
- 감지한 레이어별 누락 파일을 표시합니다.
- 모달을 닫으면 파일 선택으로 포커스를 복원하고 다른 ZIP을 바로 선택할 수 있습니다.
- 오류 안내가 팝업 본문과 결과 레이아웃을 밀어내지 않도록 분리했습니다.

### 검증 환경 보강

- Chrome for Testing을 사용해 브라우저 회귀 검사를 실행합니다.
- SHP 누락 모달과 기존 다운로드 권한 복원 흐름을 CI에서 확인합니다.
- Chrome 137 이후 공식 Chrome에서 제한된 명령줄 확장 로딩 방식에 대응했습니다.

Chrome Web Store에서 자동으로 업데이트됩니다. 압축 해제된 개발 빌드를 사용하는 경우 `npm run build` 후 `chrome://extensions`에서 확장 프로그램을 새로고침해 주세요.
